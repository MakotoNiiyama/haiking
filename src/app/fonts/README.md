# fonts ディレクトリ

ここに「夜すがら手書きフォント」のファイルを配置してください。

## 手順

1. [夜すがら手書きフォント] をダウンロード
   - フォントACなどの配布サイトから `.ttf` または `.otf` を取得
   - 作者: まるまる氏 / ライセンス: 個人・商用無料

2. ダウンロードしたファイルを **このディレクトリ** に配置
   - ファイル名: `yosugara.ttf`（または `.otf` の場合は後述を参考に変更）
   - 配置パス: `src/app/fonts/yosugara.ttf`

3. フォントファイルを置いたら、`layout.tsx` の `yosugaraFont` の
   コメントアウトを外すだけで有効になります。

## ファイル名が .otf の場合

`layout.tsx` の src を `./fonts/yosugara.otf` に変更してください。
